# 悉尼租房攻略

## 找房渠道
主要渠道:Domain、Realestate(整租)、Flatmates(合租)、今日悉尼/小红书(华人房源)。学校也有住宿服务。

## 押金(Bond)
押金通常是 4 周房租,必须交到政府的 Rental Bonds Online,房东不能私吞。退房时如果没有损坏,押金会退回。

## 区域选择
市中心/CBD 贵但上学方便;内西区(Newtown、Glebe)文艺、租金中等;华人区(Hurstville、Burwood)生活便利、中餐多;大学周边(UNSW 附近的 Kensington、Kingsford)学生多。

## 注意事项
签合同前看清楚是否包 bill(水电网)。澳洲租房通常不带家具,需要自己买。看房要趁早,好房子走得快。
